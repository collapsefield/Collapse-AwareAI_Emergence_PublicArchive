## What CAAI is now

Collapse Aware AI (CAAI) is proprietary middleware for **governed retained-state behavioural selection**.

It is designed to control whether retained history should be allowed to influence **which permitted behaviour wins**, rather than treating retrieved memory as automatic authority.

> **Retained history is eligible evidence, not automatic authority.**

The current programme has two distinct layers:

### Core Gold Build

The frozen commercial selector foundation, with public-safe accepted capabilities including:

- selection among host-supplied permitted candidate behaviours/actions;
- reference and governed retained-state conditions;
- persistence and restart recall;
- deterministic replay in tested conditions;
- revision / revocation of retained state;
- durable decision identity and evidence in the integrated evaluation lineage;
- managed evaluation and customer-safe evidence export.

### Evolution 2

The richer continuity engineering branch, now including accepted engineering checkpoints for:

- structured ContinuityFrame interpretation;
- bounded hybrid retained-state retrieval;
- Open Loops / Reopen Semantics;
- Interaction Fit;
- suppression / bounded proactive controls;
- Confidence / Clarification;
- Contradiction / Change Surfacing;
- record-only Outcomes;
- Agent Self-History;
- richer bounded behavioural signals;
- Session Observation foundation;
- Engineering Tuning;
- a restart-safe local Engineer Model with text and microphone speech-to-text input.

Evolution 2 remains an **Engineering build rather than a finished Production release**.

## Game / NPC and simulation direction

The architecture is host-neutral. Games and simulations are a natural fit because the host can supply authoritative player/NPC identities, world state, quests, witnessed events, permitted actions and save/restart identity.

The host remains authoritative for world truth and execution. CAAI can govern whether retained history should change which permitted behaviour wins.

The current public position is evaluation / adapter potential, not a claim of a finished Unity, Unreal or Godot production SDK.
